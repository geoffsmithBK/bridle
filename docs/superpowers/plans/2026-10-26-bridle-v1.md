# bridle v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build bridle: a minimal, fully readable terminal coding harness (read/bash/edit/write tools, per-action approval, Ratatui full-screen UI) for local models served by llama.cpp.

**Architecture:** One binary crate with a library. An agent thread owns the conversation and runs the loop (model call → tool calls → results → model call). The UI thread draws with Ratatui and handles keys. The two talk only through `events.rs` types over `std::sync::mpsc` channels. There is no async runtime: HTTP is blocking `ureq`, and bash runs as a child process that the agent polls.

**Tech Stack:** Rust 2024 edition (cargo 1.99), ratatui 0.30 (with re-exported crossterm 0.29), ureq 3, serde/serde_json, similar 3, lexopt 0.3, libc 0.2, anyhow.

**Spec:** `docs/superpowers/specs/2026-10-26-bridle-design.md`

## Global Constraints

- Platforms: macOS and Linux. Use POSIX facilities only (`setsid`, `killpg`, `localtime_r`) and no macOS-only commands.
- Dependencies: exactly those in Task 1's `Cargo.toml`. Add none without a stated reason.
- Boundary: `agent`, `llm`, `tools`, `log` never import `ratatui`/`crossterm`; `ui` never does HTTP or runs tools.
- Default server URL: `http://127.0.0.1:9931`.
- Approval required for `bash`, `edit`, `write`; never for `read`.
- Guard blocklist words: `sudo`, `su`, `doas`, `pkexec`, `run0`, plus the phrase `with administrator privileges`. The error text is `privilege escalation is not permitted in bridle.`
- AGENTS.md is only prompt text. Nothing may ever read it as configuration.
- Every assistant tool call in the history gets exactly one tool result.
- Reasoning is never sent back to the model. The UI shows only a timer line (`▸ thinking… Ns`, then `▸ thought for Ns`) unless it is expanded with Ctrl-X t.
- Limits: read 2000 lines/2000 chars per line; bash timeout 120 s default, 600 s max; tool output 30,000 chars; AGENTS.md 32 KB; 50 model requests per user message before asking.
- Logs: `<launch dir>/.bridle/sessions/<stamp>.md` and `.jsonl`, plus `.bridle/.gitignore` containing `*`.
- Formatting: `rustfmt.toml` (`max_width = 110`, `use_small_heuristics = "Max"`). Each task ends with `cargo clippy --all-targets` showing no warnings and `cargo fmt --check` passing.

## Review Focus

The spec doesn't spell these out, but they're the inputs most likely to bite a real user. Each one has a test in the task that owns the code:

- **The server goes down mid-session and comes back.** The status line must return to online after the next successful request. Task 7: `status_returns_to_online_when_server_recovers`.
- **Pasting multi-line code into the input.** It must insert newlines and never submit, and a paste while an approval is open must never answer it. Task 9: `paste_inserts_newlines_without_submitting`, `paste_during_approval_never_answers_it`.
- **A command prints bytes that aren't UTF-8** (binary output, a mis-encoded file). They're replaced with U+FFFD and nothing crashes. Task 4: `non_utf8_output_is_replaced_not_fatal`.
- **A command prints one enormous line** (minified JSON, `cat` of a bundle). The model gets the head and tail plus an omission marker. Task 4: `one_huge_line_is_truncated_for_the_model`.
- **Non-ASCII text in the input box** (accents, CJK, emoji). Each key moves one character, and nothing panics on a character boundary. Task 8: `multibyte_characters_are_single_steps`.

## How this plan was verified

The code in this plan is not a sketch. It was written and tested in a scratch copy, and then the tasks were replayed in order in a clean repository. //! The OpenAI chat-completions message format, as serde types.

````rust
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct FunctionCall {
    pub name: String,
    /// JSON-encoded arguments, exactly as the model produced them.
    pub arguments: String,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct ToolCall {
    pub id: String,
    #[serde(rename = "type")]
    pub kind: String,
    pub function: FunctionCall,
}

/// One entry in the conversation history sent to the model.
///
/// Reasoning is deliberately absent: it is shown and logged, never sent back.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "role", rename_all = "lowercase")]
pub enum Message {
    System {
        content: String,
    },
    User {
        content: String,
    },
    Assistant {
        content: String,
        #[serde(default, skip_serializing_if = "Vec::is_empty")]
        tool_calls: Vec<ToolCall>,
    },
    Tool {
        tool_call_id: String,
        content: String,
    },
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Serialize, Deserialize)]
pub struct Usage {
    pub prompt_tokens: u64,
    pub completion_tokens: u64,
    pub total_tokens: u64,
}

/// A fully assembled model response.
#[derive(Debug, Clone, PartialEq, Default)]
pub struct Completion {
    pub content: String,
    pub reasoning: String,
    pub tool_calls: Vec<ToolCall>,
    pub finish_reason: Option<String>,
    pub usage: Option<Usage>,
    pub tokens_per_sec: Option<f64>,
}
````

````rust
//! The contract between the agent core and the UI.

use crate::llm::types::Usage;
use std::path::PathBuf;

/// UI → core.
#[derive(Debug, Clone, PartialEq)]
pub enum Command {
    /// A user message for the model.
    Submit(String),
    /// A `!command` typed by the user (without the `!`).
    UserShell(String),
    Approve,
    /// Deny the pending approval, optionally with a reason for the model.
    Deny(Option<String>),
    Interrupt,
    /// Clear the conversation and start new log files.
    NewSession,
    Quit,
}

/// What the user is being asked to approve.
#[derive(Debug, Clone, PartialEq)]
pub struct ApprovalRequest {
    /// e.g. "Approve bash?"
    pub title: String,
    /// Path being changed, or empty.
    pub subject: String,
    /// The exact command, a unified diff, or full new-file content.
    pub body: String,
    pub outside_project: bool,
    pub overwrite: bool,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ToolStatus {
    Ok,
    Error,
    Denied,
    Cancelled,
}

/// Core → UI.
#[derive(Debug, Clone, PartialEq)]
pub enum AgentEvent {
    ServerStatus {
        online: bool,
        model: String,
        n_ctx: u64,
    },
    ReasoningDelta(String),
    TextDelta(String),
    /// A complete tool call was received from the model.
    ToolCallParsed {
        id: String,
        name: String,
        summary: String,
    },
    ApprovalNeeded(ApprovalRequest),
    /// One line of live output from a running command.
    ToolOutput {
        id: String,
        line: String,
    },
    ToolResult {
        id: String,
        status: ToolStatus,
        content: String,
    },
    /// Result of a `!command`.
    ShellResult {
        command: String,
        output: String,
    },
    CwdChanged(PathBuf),
    TurnDone {
        usage: Option<Usage>,
        tokens_per_sec: Option<f64>,
        interrupted: bool,
    },
    /// A failed request; the text should go back into the input box.
    RestoreInput(String),
    /// Pretty-printed JSON of one request/response exchange, for the inspector.
    Wire(String),
    Error(String),
    /// Something worth a dim line in the conversation (e.g. AGENTS.md loaded).
    Info(String),
    /// The core finished handling a command and is waiting for the next one.
    Idle,
}
````

````rust
//! Local time formatting without a date crate, via libc.

/// Local time broken into fields: (year, month, day, hour, minute, second).
fn local_now() -> (i32, u32, u32, u32, u32, u32) {
    let now = std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .map(|d| d.as_secs() as libc::time_t)
        .unwrap_or(0);
    // SAFETY: localtime_r only writes into the struct we pass it.
    let mut tm: libc::tm = unsafe { std::mem::zeroed() };
    unsafe { libc::localtime_r(&now, &mut tm) };
    (
        tm.tm_year + 1900,
        (tm.tm_mon + 1) as u32,
        tm.tm_mday as u32,
        tm.tm_hour as u32,
        tm.tm_min as u32,
        tm.tm_sec as u32,
    )
}

/// "2026-10-26"
pub fn today() -> String {
    let (y, mo, d, ..) = local_now();
    format!("{y:04}-{mo:02}-{d:02}")
}

/// "2026-10-26T18-51-02" (safe for file names)
pub fn file_stamp() -> String {
    let (y, mo, d, h, mi, s) = local_now();
    format!("{y:04}-{mo:02}-{d:02}T{h:02}-{mi:02}-{s:02}")
}
````

````rust
//! Assembles a streamed (SSE) chat completion into one `Completion`.
//!
//! The server sends many small `data: {...}` lines. Text and reasoning arrive
//! as fragments to append. Tool calls arrive keyed by `index`: the first
//! fragment for an index carries `id` and `function.name`, later fragments
//! carry pieces of `function.arguments` that must be concatenated. Usage
//! arrives in a final chunk with an empty `choices` array.

use crate::llm::types::{Completion, FunctionCall, ToolCall, Usage};
use anyhow::{Context, Result};
use serde_json::Value;
use std::collections::BTreeMap;

/// A piece of the response worth showing to the user as it arrives.
#[derive(Debug, Clone, PartialEq)]
pub enum Delta {
    Reasoning(String),
    Text(String),
}

#[derive(Debug, Default)]
struct PartialCall {
    id: String,
    name: String,
    arguments: String,
}

#[derive(Debug, Default)]
pub struct Accumulator {
    content: String,
    reasoning: String,
    calls: BTreeMap<u64, PartialCall>,
    finish_reason: Option<String>,
    usage: Option<Usage>,
    tokens_per_sec: Option<f64>,
    done: bool,
}

impl Accumulator {
    pub fn new() -> Self {
        Self::default()
    }

    /// True once `data: [DONE]` has been seen.
    pub fn is_done(&self) -> bool {
        self.done
    }

    /// Feed one line of the SSE stream. Returns the displayable pieces it contained.
    pub fn push_line(&mut self, line: &str) -> Result<Vec<Delta>> {
        let line = line.trim_end_matches(['\r', '\n']);
        let Some(data) = line.strip_prefix("data:") else {
            // Blank separators, ": comments", "event:" lines: nothing to do.
            return Ok(vec![]);
        };
        let data = data.trim_start();
        if data == "[DONE]" {
            self.done = true;
            return Ok(vec![]);
        }
        let chunk: Value = serde_json::from_str(data).with_context(|| format!("bad SSE chunk: {data}"))?;

        if let Some(usage) = chunk.get("usage").filter(|u| !u.is_null()) {
            self.usage = serde_json::from_value(usage.clone()).ok();
        }
        if let Some(tps) = chunk["timings"]["predicted_per_second"].as_f64() {
            self.tokens_per_sec = Some(tps);
        }

        let mut out = vec![];
        let Some(choice) = chunk["choices"].get(0) else {
            return Ok(out);
        };
        if let Some(reason) = choice["finish_reason"].as_str() {
            self.finish_reason = Some(reason.to_string());
        }
        let delta = &choice["delta"];
        if let Some(r) = delta["reasoning_content"].as_str().filter(|s| !s.is_empty()) {
            self.reasoning.push_str(r);
            out.push(Delta::Reasoning(r.to_string()));
        }
        if let Some(t) = delta["content"].as_str().filter(|s| !s.is_empty()) {
            self.content.push_str(t);
            out.push(Delta::Text(t.to_string()));
        }
        if let Some(calls) = delta["tool_calls"].as_array() {
            for (pos, call) in calls.iter().enumerate() {
                let index = call["index"].as_u64().unwrap_or(pos as u64);
                let entry = self.calls.entry(index).or_default();
                if let Some(id) = call["id"].as_str() {
                    entry.id = id.to_string();
                }
                if let Some(name) = call["function"]["name"].as_str() {
                    entry.name.push_str(name);
                }
                if let Some(args) = call["function"]["arguments"].as_str() {
                    entry.arguments.push_str(args);
                }
            }
        }
        Ok(out)
    }

    /// The assembled completion. Calls without an id get a synthetic one.
    pub fn finish(self) -> Completion {
        let tool_calls = self
            .calls
            .into_iter()
            .map(|(index, c)| ToolCall {
                id: if c.id.is_empty() { format!("call_{index}") } else { c.id },
                kind: "function".to_string(),
                function: FunctionCall { name: c.name, arguments: c.arguments },
            })
            .collect();
        Completion {
            content: self.content,
            reasoning: self.reasoning,
            tool_calls,
            finish_reason: self.finish_reason,
            usage: self.usage,
            tokens_per_sec: self.tokens_per_sec,
        }
    }
}
````

````rust
//! HTTP to llama-server: build requests, read the SSE stream.

use crate::llm::stream::{Accumulator, Delta};
use crate::llm::types::{Completion, Message};
use serde_json::{Value, json};
use std::io::BufRead;

#[derive(Debug, Clone, PartialEq)]
pub enum LlmError {
    /// Could not connect, or the connection dropped.
    Offline(String),
    /// The server answered with a non-2xx status.
    Http { status: u16, body: String },
    /// The server's stream did not make sense.
    Protocol(String),
}

impl std::fmt::Display for LlmError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            LlmError::Offline(e) => write!(f, "server offline: {e}"),
            LlmError::Http { status, body } => write!(f, "HTTP {status}: {body}"),
            LlmError::Protocol(e) => write!(f, "protocol error: {e}"),
        }
    }
}

/// How a stream ended.
#[derive(Debug, Clone, PartialEq)]
pub enum Streamed {
    Complete(Completion),
    /// `on_delta` returned false; this is whatever arrived before that.
    Aborted(Completion),
}

/// Anything that can stream a chat completion. `LlamaClient` talks to the
/// real server; tests use a scripted fake.
pub trait Llm: Send {
    /// Stream one completion for `request`. `on_delta` is called for each
    /// displayable piece; returning false aborts the stream.
    fn stream(&self, request: &Value, on_delta: &mut dyn FnMut(Delta) -> bool) -> Result<Streamed, LlmError>;

    /// Ask the server which model it serves and its context size.
    fn probe(&self) -> Result<(String, u64), LlmError>;

    /// Raw SSE lines from the most recent stream, if they were kept.
    fn take_raw(&self) -> Vec<String> {
        vec![]
    }
}

/// The request body for one model call.
pub fn chat_request(model: &str, messages: &[Message], tools: &Value) -> Value {
    json!({
        "model": model,
        "messages": messages,
        "tools": tools,
        "stream": true,
        "stream_options": { "include_usage": true },
    })
}

/// Read an SSE stream to the end (or until `on_delta` returns false).
/// If `raw` is given, every non-blank line is copied into it.
pub fn read_stream(
    reader: impl BufRead,
    mut raw: Option<&mut Vec<String>>,
    on_delta: &mut dyn FnMut(Delta) -> bool,
) -> Result<Streamed, LlmError> {
    let mut acc = Accumulator::new();
    for line in reader.lines() {
        let line = line.map_err(|e| LlmError::Offline(e.to_string()))?;
        if line.is_empty() {
            continue;
        }
        if let Some(raw) = raw.as_deref_mut() {
            raw.push(line.clone());
        }
        let deltas = acc.push_line(&line).map_err(|e| LlmError::Protocol(e.to_string()))?;
        for d in deltas {
            if !on_delta(d) {
                return Ok(Streamed::Aborted(acc.finish()));
            }
        }
        if acc.is_done() {
            break;
        }
    }
    Ok(Streamed::Complete(acc.finish()))
}

pub struct LlamaClient {
    agent: ureq::Agent,
    base_url: String,
    /// Keep raw SSE lines of each stream for the wire log (`--wire-raw`).
    keep_raw: bool,
    last_raw: std::sync::Mutex<Vec<String>>,
}

impl LlamaClient {
    pub fn new(base_url: &str, keep_raw: bool) -> Self {
        // Non-2xx responses are returned as responses, so we can show their body.
        let agent = ureq::Agent::config_builder().http_status_as_error(false).build().into();
        Self {
            agent,
            base_url: base_url.trim_end_matches('/').to_string(),
            keep_raw,
            last_raw: Default::default(),
        }
    }

    fn fetch_models(&self) -> Result<(String, u64), LlmError> {
        let resp = self
            .agent
            .get(format!("{}/v1/models", self.base_url))
            .call()
            .map_err(|e| LlmError::Offline(e.to_string()))?;
        let body = resp.into_body().read_to_string().map_err(|e| LlmError::Offline(e.to_string()))?;
        let v: Value = serde_json::from_str(&body).map_err(|e| LlmError::Protocol(e.to_string()))?;
        let model =
            v["data"][0]["id"].as_str().ok_or_else(|| LlmError::Protocol("no models listed".into()))?;
        let n_ctx = v["data"][0]["meta"]["n_ctx"].as_u64().unwrap_or(0);
        Ok((model.to_string(), n_ctx))
    }
}

impl Llm for LlamaClient {
    fn stream(&self, request: &Value, on_delta: &mut dyn FnMut(Delta) -> bool) -> Result<Streamed, LlmError> {
        let resp = self
            .agent
            .post(format!("{}/v1/chat/completions", self.base_url))
            .header("Content-Type", "application/json")
            .send(request.to_string())
            .map_err(|e| LlmError::Offline(e.to_string()))?;
        let status = resp.status().as_u16();
        if !(200..300).contains(&status) {
            let body = resp.into_body().read_to_string().unwrap_or_default();
            return Err(LlmError::Http { status, body });
        }
        let reader = std::io::BufReader::new(resp.into_body().into_reader());
        let mut raw = Vec::new();
        let result = read_stream(reader, self.keep_raw.then_some(&mut raw), on_delta);
        *self.last_raw.lock().unwrap() = raw;
        result
    }

    fn probe(&self) -> Result<(String, u64), LlmError> {
        self.fetch_models()
    }

    fn take_raw(&self) -> Vec<String> {
        std::mem::take(&mut *self.last_raw.lock().unwrap())
    }
}
````

````rust
//! Path resolution for tool arguments.

use std::path::{Component, Path, PathBuf};

/// Resolve a user/model-supplied path against `cwd`, expanding a leading `~`,
/// and normalize `.` and `..` lexically (the file may not exist yet).
pub fn resolve(cwd: &Path, raw: &str) -> PathBuf {
    let expanded = if raw == "~" || raw.starts_with("~/") {
        let home = std::env::var("HOME").unwrap_or_default();
        PathBuf::from(home).join(raw.trim_start_matches('~').trim_start_matches('/'))
    } else {
        PathBuf::from(raw)
    };
    let joined = if expanded.is_absolute() { expanded } else { cwd.join(expanded) };
    normalize(&joined)
}

fn normalize(path: &Path) -> PathBuf {
    let mut out = PathBuf::new();
    for c in path.components() {
        match c {
            Component::CurDir => {}
            Component::ParentDir => {
                out.pop();
            }
            other => out.push(other),
        }
    }
    out
}

/// True if `path` is not inside `root`.
pub fn is_outside(root: &Path, path: &Path) -> bool {
    !path.starts_with(root)
}
````

````rust
//! The `read` tool: numbered lines, paged.

use std::path::Path;

pub const MAX_LINES: usize = 2000;
pub const MAX_LINE_CHARS: usize = 2000;

/// Read `path` and format lines `offset..offset+limit` (1-based offset).
/// Errors are returned as the message the model should see.
pub fn read_file(path: &Path, offset: Option<usize>, limit: Option<usize>) -> Result<String, String> {
    let shown = path.display();
    if path.is_dir() {
        return Err(format!("{shown} is a directory. Use bash with ls to list it."));
    }
    let bytes = std::fs::read(path).map_err(|e| format!("cannot read {shown}: {e}"))?;
    if bytes[..bytes.len().min(8192)].contains(&0) {
        return Err(format!("{shown} looks like a binary file."));
    }
    let text = String::from_utf8(bytes).map_err(|_| format!("{shown} is not valid UTF-8."))?;
    let lines: Vec<&str> = text.lines().collect();
    let total = lines.len();
    if total == 0 {
        return Ok(format!("[{shown} is empty]"));
    }
    let start = offset.unwrap_or(1).max(1);
    if start > total {
        return Err(format!("offset {start} is past the end of {shown} ({total} lines)."));
    }
    let limit = limit.unwrap_or(MAX_LINES).clamp(1, MAX_LINES);
    let end = (start - 1 + limit).min(total);

    let mut out = String::new();
    for (i, line) in lines[start - 1..end].iter().enumerate() {
        let n = start + i;
        if line.chars().count() > MAX_LINE_CHARS {
            let cut: String = line.chars().take(MAX_LINE_CHARS).collect();
            out.push_str(&format!("{n:>6}│ {cut}… [line truncated]\n"));
        } else {
            out.push_str(&format!("{n:>6}│ {line}\n"));
        }
    }
    if end < total {
        out.push_str(&format!(
            "[lines {start}–{end} of {total} — call read again with offset={} to continue]\n",
            end + 1
        ));
    }
    Ok(out)
}
````

````rust
//! The `edit` tool's matching logic: exact, unique replacement.

/// Return `content` with the single occurrence of `old` replaced by `new`.
/// Errors are the messages the model should see.
pub fn plan_edit(path: &str, content: &str, old: &str, new: &str) -> Result<String, String> {
    if old.is_empty() {
        return Err("old_text must not be empty. Use write to create a file.".into());
    }
    let starts: Vec<usize> = content.match_indices(old).map(|(i, _)| i).collect();
    match starts.len() {
        0 => Err(format!(
            "old_text not found in {path}. The file may have changed — read it again. \
             Check whitespace and indentation exactly."
        )),
        1 => Ok(content.replacen(old, new, 1)),
        n => {
            let lines: Vec<String> =
                starts.iter().map(|&i| (content[..i].matches('\n').count() + 1).to_string()).collect();
            Err(format!(
                "old_text matches {n} times (lines {}). Include more surrounding lines to make it unique.",
                lines.join(", ")
            ))
        }
````

````rust
/// (lines removed, lines added)
pub fn diff_stats(old: &str, new: &str) -> (usize, usize) {
    let diff = TextDiff::from_lines(old, new);
    let mut removed = 0;
    let mut added = 0;
    for change in diff.iter_all_changes() {
        match change.tag() {
            ChangeTag::Delete => removed += 1,
            ChangeTag::Insert => added += 1,
            ChangeTag::Equal => {}
        }
    }

/// Write `new` to `path`, but only if the file still holds exactly
/// `expected_old` (or still doesn't exist, when `expected_old` is None).
/// This guarantees that what the user approved is what gets written.
pub fn apply_write(path: &Path, expected_old: Option<&str>, new: &str) -> Result<(), String> {
    let shown = path.display();
    let current = std::fs::read(path).ok();
    let unchanged = match (expected_old, &current) {
        (None, None) => true,
        (Some(old), Some(cur)) => old.as_bytes() == cur.as_slice(),
        _ => false,
    };
    if !unchanged {
        return Err(format!("{shown} changed since the change was proposed; read it again."));
    }
    if let Some(parent) = path.parent() {
        std::fs::create_dir_all(parent).map_err(|e| format!("cannot create {}: {e}", parent.display()))?;
    }
    std::fs::write(path, new).map_err(|e| format!("cannot write {shown}: {e}"))
}
````

````rust
//! Keeping bash away from privilege escalation. This is not a sandbox; the
//! user's approval of each command is the real protection. See spec §6.5.

use std::path::{Path, PathBuf};

const BLOCKED_WORDS: &[&str] = &["sudo", "su", "doas", "pkexec", "run0"];

/// Reject commands that mention privilege-escalation tools.
pub fn check_command(command: &str) -> Result<(), String> {
    let lower = command.to_lowercase();
    let mentions_word = lower
        .split(|c: char| !(c.is_ascii_alphanumeric() || c == '_' || c == '-'))
        .any(|word| BLOCKED_WORDS.contains(&word));
    if mentions_word || lower.contains("with administrator privileges") {
        return Err("privilege escalation is not permitted in bridle.".into());
    }
    Ok(())
}

/// Create a directory holding a `sudo` that always fails. It is put first on
/// PATH for every command bridle runs.
pub fn make_shim_dir() -> std::io::Result<PathBuf> {
    use std::os::unix::fs::PermissionsExt;
    let dir = std::env::temp_dir().join(format!("bridle-shim-{}", std::process::id()));
    std::fs::create_dir_all(&dir)?;
    let shim = dir.join("sudo");
    std::fs::write(&shim, "#!/bin/sh\necho 'sudo is disabled inside bridle' >&2\nexit 1\n")?;
    std::fs::set_permissions(&shim, std::fs::Permissions::from_mode(0o755))?;
    Ok(dir)
}

/// PATH for child processes: the shim directory first.
pub fn child_path(shim_dir: &Path) -> String {
    let current = std::env::var("PATH").unwrap_or_default();
    format!("{}:{current}", shim_dir.display())
}
````

````rust
//! The `bash` tool: run a command in its own session, stream its output.

use crate::tools::guard;
use std::io::BufRead;
use std::os::unix::process::CommandExt;
use std::path::Path;
use std::process::{Command, Stdio};
use std::sync::mpsc;
use std::time::{Duration, Instant};

pub const DEFAULT_TIMEOUT: u64 = 120;
pub const MAX_TIMEOUT: u64 = 600;
pub const MAX_OUTPUT_CHARS: usize = 30_000;

#[derive(Debug, Clone, PartialEq)]
pub enum Exit {
    Code(i32),
    Signal,
    Timeout,
    Interrupted,
}

#[derive(Debug, Clone, PartialEq)]
pub struct BashResult {
    pub output: String,
    pub exit: Exit,
}

impl BashResult {
    /// The text the model sees: (truncated) output plus how it ended.
    pub fn for_model(&self) -> String {
        let status = match self.exit {
            Exit::Code(n) => format!("[exit code: {n}]"),
            Exit::Signal => "[killed by signal]".to_string(),
            Exit::Timeout => "[killed: timeout]".to_string(),
            Exit::Interrupted => "[killed: interrupted]".to_string(),
        };
        let out = truncate_middle(&self.output, MAX_OUTPUT_CHARS);
        if out.is_empty() { status } else { format!("{}\n{status}", out.trim_end_matches('\n')) }
    }
}

/// Keep the start and end of `s` (20% / 80%) when it exceeds `max` chars.
pub fn truncate_middle(s: &str, max: usize) -> String {
    let total = s.chars().count();
    if total <= max {
        return s.to_string();
    }
    let head = max / 5;
    let tail = max - head;
    let omitted = total - head - tail;
    let start: String = s.chars().take(head).collect();
    let end: String = s.chars().skip(total - tail).collect();
    format!("{start}\n[… {omitted} chars omitted …]\n{end}")
}

/// Run `command` with `bash -c` in `cwd`.
///
/// - New session (`setsid`): no controlling terminal, own process group.
/// - stdin is /dev/null; stdout and stderr share one pipe, so they interleave
///   in the order written.
/// - `on_line` sees each output line as it arrives.
/// - `cancelled` is polled every 50 ms; true kills the process group.
/// - When the command exits, any leftover background processes in its group
///   are killed too.
pub fn run(
    command: &str,
    cwd: &Path,
    shim_dir: &Path,
    timeout_secs: u64,
    on_line: &mut dyn FnMut(&str),
    cancelled: &mut dyn FnMut() -> bool,
) -> std::io::Result<BashResult> {
    let (reader, writer) = std::io::pipe()?;
    let mut cmd = Command::new("bash");
    cmd.arg("-c")
        .arg(command)
        .current_dir(cwd)
        .env("PATH", guard::child_path(shim_dir))
        .env("SUDO_ASKPASS", "/usr/bin/false")
        .stdin(Stdio::null())
        .stdout(writer.try_clone()?)
        .stderr(writer);
    // SAFETY: setsid is async-signal-safe and we touch nothing else.
    unsafe {
        cmd.pre_exec(|| {
            if libc::setsid() == -1 {
                return Err(std::io::Error::last_os_error());
            }
            Ok(())
        });
    }
    let mut child = cmd.spawn()?;
    drop(cmd); // closes our copies of the pipe's write end
    let pgid = child.id() as libc::pid_t;

    let (tx, rx) = mpsc::channel::<String>();
    let reader_thread = std::thread::spawn(move || {
        let mut r = std::io::BufReader::new(reader);
        let mut buf = Vec::new();
        while let Ok(n) = r.read_until(b'\n', &mut buf) {
            if n == 0 {
                break;
            }
            let _ = tx.send(String::from_utf8_lossy(&buf).into_owned());
            buf.clear();
        }
    });

    let deadline = Instant::now() + Duration::from_secs(timeout_secs.clamp(1, MAX_TIMEOUT));
    let mut output = String::new();
    let drain = |output: &mut String, on_line: &mut dyn FnMut(&str)| {
        while let Ok(chunk) = rx.try_recv() {
            on_line(chunk.trim_end_matches('\n'));
            output.push_str(&chunk);
        }
    };
    let exit = loop {
        drain(&mut output, on_line);
        if let Some(status) = child.try_wait()? {
            break match status.code() {
                Some(code) => Exit::Code(code),
                None => Exit::Signal,
            };
        }
        if cancelled() {
            kill_group(pgid);
            let _ = child.wait();
            break Exit::Interrupted;
        }
        if Instant::now() >= deadline {
            kill_group(pgid);
            let _ = child.wait();
            break Exit::Timeout;
        }
        std::thread::sleep(Duration::from_millis(50));
    };
    // Background jobs may still hold the pipe open; end them so the reader finishes.
    kill_group(pgid);
    // Collect the remaining output. A process that escaped the group could keep
    // the pipe open forever, so stop waiting after 200 ms of silence.
    while let Ok(chunk) = rx.recv_timeout(Duration::from_millis(200)) {
        on_line(chunk.trim_end_matches('\n'));
        output.push_str(&chunk);
    }
    drop(reader_thread);
    Ok(BashResult { output, exit })
}

fn kill_group(pgid: libc::pid_t) {
    // SAFETY: plain syscall; an already-dead group just returns ESRCH.
    unsafe {
        libc::killpg(pgid, libc::SIGKILL);
    }
}
````

````rust
//! A tool call goes through two steps:

//!    (for edits, the new file content). It decides whether approval is needed.

#[derive(Debug, Clone)]
pub struct ToolContext {
    /// Session working directory (changed only by the user's `!cd`).
    pub cwd: PathBuf,
    /// The directory bridle was launched in.
    pub project_root: PathBuf,
    /// Directory holding the failing `sudo` shim.
    pub shim_dir: PathBuf,
}

/// A fully worked-out action, ready to run.
#[derive(Debug, Clone, PartialEq)]
pub enum Action {
    Read {
        path: PathBuf,
        offset: Option<usize>,
        limit: Option<usize>,
    },
    Bash {
        command: String,
        timeout: u64,
    },
    /// Used by both edit and write.
    WriteFile {
        path: PathBuf,
        expected_old: Option<String>,
        new_content: String,
        edit: bool,
    },
}

#[derive(Debug, Clone, PartialEq)]
pub enum Prepared {
    Ready(Action),
    NeedsApproval(ApprovalRequest, Action),
    /// The message for the model (without the "Error: " prefix).
    Failed(String),
}

/// One-line description of a call for the UI, e.g. "bash  cargo build".
pub fn summarize(name: &str, arguments: &str) -> String {
    let args: Value = serde_json::from_str(arguments).unwrap_or(Value::Null);
    let detail = match name {
        "bash" => args["command"].as_str().unwrap_or("").lines().next().unwrap_or("").to_string(),
        _ => args["path"].as_str().unwrap_or("").to_string(),
    };
    format!("{name}  {detail}")
}

fn str_arg<'a>(args: &'a Value, key: &str) -> Result<&'a str, String> {
    args[key].as_str().ok_or_else(|| format!("missing string argument '{key}'"))
}

/// Parse a tool call and work out what it will do.
pub fn prepare(name: &str, arguments: &str, ctx: &ToolContext) -> Prepared {
    match prepare_inner(name, arguments, ctx) {
        Ok(p) => p,
        Err(msg) => Prepared::Failed(msg),
    }
}

fn prepare_inner(name: &str, arguments: &str, ctx: &ToolContext) -> Result<Prepared, String> {
    let args: Value = serde_json::from_str(arguments)
        .map_err(|e| format!("arguments were not valid JSON ({e}). Raw arguments: {arguments}"))?;
    match name {
        "read" => {
            let path = paths::resolve(&ctx.cwd, str_arg(&args, "path")?);
            let offset = args["offset"].as_u64().map(|n| n as usize);
            let limit = args["limit"].as_u64().map(|n| n as usize);
            Ok(Prepared::Ready(Action::Read { path, offset, limit }))
        }
        "bash" => {
            let command = str_arg(&args, "command")?.to_string();
            guard::check_command(&command)?;
            let timeout =
                args["timeout"].as_u64().unwrap_or(bash::DEFAULT_TIMEOUT).clamp(1, bash::MAX_TIMEOUT);
            let approval = ApprovalRequest {
                title: "Approve bash?".into(),
                subject: String::new(),
                body: command.clone(),
                outside_project: false,
                overwrite: false,
            };
            Ok(Prepared::NeedsApproval(approval, Action::Bash { command, timeout }))
        }
        "edit" => {
            let raw = str_arg(&args, "path")?;
            let path = paths::resolve(&ctx.cwd, raw);
            let old = std::fs::read_to_string(&path).map_err(|e| format!("cannot read {raw}: {e}"))?;
            let new = edit::plan_edit(raw, &old, str_arg(&args, "old_text")?, str_arg(&args, "new_text")?)?;
            let approval = ApprovalRequest {
                title: "Approve edit?".into(),
                subject: path.display().to_string(),
                body: write::unified_diff(raw, &old, &new),
                outside_project: paths::is_outside(&ctx.project_root, &path),
                overwrite: false,
            };
            Ok(Prepared::NeedsApproval(
                approval,
                Action::WriteFile { path, expected_old: Some(old), new_content: new, edit: true },
            ))
        }
        "write" => {
            let raw = str_arg(&args, "path")?;
            let path = paths::resolve(&ctx.cwd, raw);
            let content = str_arg(&args, "content")?.to_string();
            if path.is_dir() {
                return Err(format!("{raw} is a directory."));
            }
            let old = std::fs::read_to_string(&path).ok();
            let body = match &old {
                Some(old) => write::unified_diff(raw, old, &content),
                None => content.clone(),
            };
            let approval = ApprovalRequest {
                title: "Approve write?".into(),
                subject: path.display().to_string(),
                body,
                outside_project: paths::is_outside(&ctx.project_root, &path),
                overwrite: old.is_some(),
            };
            Ok(Prepared::NeedsApproval(
                approval,
                Action::WriteFile { path, expected_old: old, new_content: content, edit: false },
            ))
        }
        other => Err(format!("unknown tool '{other}'. Available tools: read, bash, edit, write.")),
    }
}

/// Run a prepared action. Returns the status and the text for the model.
pub fn execute(
    action: &Action,
    ctx: &ToolContext,
    on_line: &mut dyn FnMut(&str),
    cancelled: &mut dyn FnMut() -> bool,
) -> (ToolStatus, String) {
    let result = match action {
        Action::Read { path, offset, limit } => read::read_file(path, *offset, *limit),
        Action::Bash { command, timeout } => {
            match bash::run(command, &ctx.cwd, &ctx.shim_dir, *timeout, on_line, cancelled) {
                Ok(r) if r.exit == bash::Exit::Interrupted => {
                    return (ToolStatus::Cancelled, r.for_model());
                }
                Ok(r) => Ok(r.for_model()),
                Err(e) => Err(format!("could not run bash: {e}")),
            }
        }
        Action::WriteFile { path, expected_old, new_content, edit } => {
            write_file(path, expected_old.as_deref(), new_content, *edit)
        }
    };
    match result {
        Ok(text) => (ToolStatus::Ok, text),
        Err(msg) => (ToolStatus::Error, format!("Error: {msg}")),
    }
}

fn write_file(path: &Path, expected_old: Option<&str>, new: &str, edit: bool) -> Result<String, String> {
    write::apply_write(path, expected_old, new)?;
    let shown = path.display();
    if edit {
        let (removed, added) = write::diff_stats(expected_old.unwrap_or(""), new);
        Ok(format!("Edited {shown} (−{removed} +{added} lines)"))
    } else {
        Ok(format!("Wrote {} bytes ({} lines) to {shown}", new.len(), new.lines().count()))
    }
}
````

````rust
//! The system prompt (adapted from early pi), plus the project's AGENTS.md.

use std::path::Path;

/// bridle's README, located at build time.
pub const README_PATH: &str = concat!(env!("CARGO_MANIFEST_DIR"), "/README.md");

/// AGENTS.md is cut to this many bytes.
pub const AGENTS_MD_LIMIT: usize = 32 * 1024;

/// Read `dir/AGENTS.md`, if present, capped at `AGENTS_MD_LIMIT`.
pub fn load_agents_md(dir: &Path) -> Option<String> {
    let text = std::fs::read_to_string(dir.join("AGENTS.md")).ok()?;
    if text.len() <= AGENTS_MD_LIMIT {
        return Some(text);
    }
    let mut cut = AGENTS_MD_LIMIT;
    while !text.is_char_boundary(cut) {
        cut -= 1;
    }
    Some(format!("{}\n[AGENTS.md truncated at 32 KB]", &text[..cut]))
}
````

````rust
//! Session logs: a readable transcript (.md) and a wire log (.jsonl).

use serde_json::Value;
use std::fs::File;
use std::io::Write;
use std::path::{Path, PathBuf};

/// Writes logs under `<root>/.bridle/sessions/`. `SessionLog::disabled()`
/// writes nothing (used in tests).
pub struct SessionLog {
    md: Option<File>,
    jsonl: Option<File>,
    pub md_path: Option<PathBuf>,
}

impl SessionLog {
    pub fn disabled() -> Self {
        Self { md: None, jsonl: None, md_path: None }
    }

    /// Open new log files named `stamp.md` / `stamp.jsonl`.
    pub fn create(project_root: &Path, stamp: &str) -> std::io::Result<Self> {
        let base = project_root.join(".bridle");
        let dir = base.join("sessions");
        std::fs::create_dir_all(&dir)?;
        let ignore = base.join(".gitignore");
        if !ignore.exists() {
            std::fs::write(&ignore, "*\n")?;
        }
        let md_path = dir.join(format!("{stamp}.md"));
        Ok(Self {
            md: Some(File::create(&md_path)?),
            jsonl: Some(File::create(dir.join(format!("{stamp}.jsonl")))?),
            md_path: Some(md_path),
        })
    }

    /// Append text to the transcript. Logging failures are ignored: a full
    /// disk should not stop the session.
    pub fn md(&mut self, text: &str) {
        if let Some(f) = &mut self.md {
            let _ = writeln!(f, "{text}");
        }
    }

    /// Append one JSON record (one line) to the wire log.
    pub fn wire(&mut self, record: &Value) {
        if let Some(f) = &mut self.jsonl {
            let _ = writeln!(f, "{record}");
        }
    }
}
````

````rust
//! Command-line flags.

pub const DEFAULT_URL: &str = "http://127.0.0.1:9931";

#[derive(Debug, Clone, PartialEq)]
pub struct Config {
    pub url: String,
    pub model: Option<String>,
    pub wire_raw: bool,
}

pub const USAGE: &str = "usage: bridle [--url URL] [--model ID] [--wire-raw]

  --url URL     llama-server base URL (default http://127.0.0.1:9931)
  --model ID    model id to request (default: the server's first model)
  --wire-raw    also log every raw SSE line to the wire log";

/// Parse flags (without the program name). Ok(None) means --help was asked for.
pub fn parse(args: impl IntoIterator<Item = String>) -> Result<Option<Config>, lexopt::Error> {
    use lexopt::prelude::*;
    let mut config = Config { url: DEFAULT_URL.to_string(), model: None, wire_raw: false };
    let mut parser = lexopt::Parser::from_args(args);
    while let Some(arg) = parser.next()? {
        match arg {
            Long("url") => config.url = parser.value()?.string()?,
            Long("model") => config.model = Some(parser.value()?.string()?),
            Long("wire-raw") => config.wire_raw = true,
            Short('h') | Long("help") => return Ok(None),
            _ => return Err(arg.unexpected()),
        }
    }
    Ok(Some(config))
}
````

````rust
use bridle::agent::{Agent, AgentOptions, parse_cd};
use bridle::events::{AgentEvent, ApprovalRequest, Command, ToolStatus};
use bridle::llm::client::{Llm, LlmError, Streamed};
use bridle::llm::stream::Delta;

use std::path::PathBuf;
use std::sync::mpsc::{Receiver, Sender, channel};
use std::sync::{Arc, Mutex};
use std::thread::JoinHandle;

/// One scripted model response.
enum Step {
    Reply { deltas: Vec<Delta>, completion: Completion },
    Fail(LlmError),
}

fn text(s: &str) -> Step {
    Step::Reply {
        deltas: vec![Delta::Reasoning("hmm".into()), Delta::Text(s.into())],
        completion: Completion { content: s.into(), reasoning: "hmm".into(), ..Default::default() },
    }
}

fn call(id: &str, name: &str, args: &str) -> ToolCall {
    ToolCall {
        id: id.into(),
        kind: "function".into(),
        function: FunctionCall { name: name.into(), arguments: args.into() },
    }
}

fn calls(cs: Vec<ToolCall>) -> Step {
    Step::Reply { deltas: vec![], completion: Completion { tool_calls: cs, ..Default::default() } }
}

struct FakeLlm {
    script: Mutex<VecDeque<Step>>,
    requests: Arc<Mutex<Vec<Value>>>,
}

impl Llm for FakeLlm {
    fn stream(&self, request: &Value, on_delta: &mut dyn FnMut(Delta) -> bool) -> Result<Streamed, LlmError> {
        self.requests.lock().unwrap().push(request.clone());
        match self.script.lock().unwrap().pop_front().expect("script ran out") {
            Step::Fail(e) => Err(e),
            Step::Reply { deltas, completion } => {
                let mut partial = Completion::default();
                for d in deltas {
                    // Like the real stream: the piece is accumulated, then shown.
                    match &d {
                        Delta::Text(t) => partial.content.push_str(t),
                        Delta::Reasoning(r) => partial.reasoning.push_str(r),
                    }
                    if !on_delta(d) {
                        return Ok(Streamed::Aborted(partial));
                    }
                }
                Ok(Streamed::Complete(completion))
            }
        }
    }

    fn probe(&self) -> Result<(String, u64), LlmError> {
        Ok(("fake-model".into(), 4096))
    }
}

struct Harness {
    cmd: Sender<Command>,
    ev: Receiver<AgentEvent>,
    handle: JoinHandle<Vec<Message>>,
    requests: Arc<Mutex<Vec<Value>>>,
    dir: PathBuf,
}

fn start(script: Vec<Step>, max_steps: usize) -> Harness {
    start_in(script, max_steps, |_| {})
}

/// Like `start`, but `setup` can put files in the project dir first.
fn start_in(script: Vec<Step>, max_steps: usize, setup: impl FnOnce(&std::path::Path)) -> Harness {
    let ctx = common::context();
    setup(&ctx.project_root);
    let dir = ctx.cwd.clone();
    let requests = Arc::new(Mutex::new(vec![]));
    let llm = FakeLlm { script: Mutex::new(script.into()), requests: requests.clone() };
    let (cmd, cmd_rx) = channel();
    let (ev_tx, ev) = channel();
    let options = AgentOptions { model: None, log: false, max_steps };
    let agent = Agent::new(llm, options, ctx, ev_tx, cmd_rx);
    let handle = std::thread::spawn(move || agent.run());
    Harness { cmd, ev, handle, requests, dir }
}

impl Harness {
    /// Collect events until Idle, answering approvals with `decide`.
    fn until_idle(&self, mut decide: impl FnMut(&ApprovalRequest) -> Command) -> Vec<AgentEvent> {
        let mut out = vec![];
        loop {
            let e = self.ev.recv_timeout(std::time::Duration::from_secs(10)).expect("no Idle");
            if let AgentEvent::ApprovalNeeded(req) = &e {
                self.cmd.send(decide(req)).unwrap();
            }
            let idle = e == AgentEvent::Idle;
            out.push(e);
            if idle {
                return out;
            }
        }
    }

    fn submit(&self, text: &str, decide: impl FnMut(&ApprovalRequest) -> Command) -> Vec<AgentEvent> {
        self.cmd.send(Command::Submit(text.into())).unwrap();
        self.until_idle(decide)
    }

    fn finish(self) -> Vec<Message> {
        self.cmd.send(Command::Quit).unwrap();
        let messages = self.handle.join().unwrap();
        assert_every_call_answered(&messages);
        messages
    }
}

fn never(_: &ApprovalRequest) -> Command {
    panic!("unexpected approval request")
}

/// The core invariant: each tool call has exactly one result, right after it.
fn assert_every_call_answered(messages: &[Message]) {
    for (i, m) in messages.iter().enumerate() {
        if let Message::Assistant { tool_calls, .. } = m {
            for (j, c) in tool_calls.iter().enumerate() {
                match messages.get(i + 1 + j) {
                    Some(Message::Tool { tool_call_id, .. }) => assert_eq!(tool_call_id, &c.id),
                    other => panic!("call {} has no result; found {other:?}", c.id),
                }
            }
        }
    }
}

fn tool_results(messages: &[Message]) -> Vec<String> {
    messages
        .iter()
        .filter_map(|m| match m {
            Message::Tool { content, .. } => Some(content.clone()),
            _ => None,
        })
        .collect()
}
````

````rust
//! The agent loop: the heart of the harness.
//!
//! The agent owns the conversation history. For each user message it calls
//! the model, runs any tool calls it asks for (after approval where needed),
//! appends the results, and calls the model again, until the model answers
//! without tool calls.
//!
//! Invariant: every tool call in the history gets exactly one tool result,
//! even when the user denies or interrupts.

use crate::events::{AgentEvent, ApprovalRequest, Command, ToolStatus};
use crate::llm::client::{Llm, LlmError, Streamed, chat_request};
use crate::llm::stream::Delta;
use crate::llm::types::{Completion, Message, ToolCall};
use crate::log::SessionLog;
use crate::tools::{self, Action, Prepared, ToolContext, bash, guard, paths};
use serde_json::{Value, json};
use std::cell::Cell;
use std::sync::mpsc::{Receiver, Sender};

pub const DEFAULT_MAX_STEPS: usize = 50;

pub struct AgentOptions {
    /// Use this model id instead of the one the server reports.
    pub model: Option<String>,
    /// Write session logs under `<project_root>/.bridle/sessions/`.
    pub log: bool,
    /// Model requests allowed per user message before asking to continue.
    pub max_steps: usize,
}

enum Decision {
    Approve,
    Deny(Option<String>),
    Interrupt,
}

pub struct Agent<L: Llm> {
    llm: L,
    options: AgentOptions,
    model: String,
    messages: Vec<Message>,
    ctx: ToolContext,
    log: SessionLog,
    events: Sender<AgentEvent>,
    commands: Receiver<Command>,
    /// Last known server state, so recovery can be reported.
    online: bool,
    /// Set when a Quit arrives while busy.
    quit: Cell<bool>,
}

impl<L: Llm> Agent<L> {
    pub fn new(
        llm: L,
        options: AgentOptions,
        ctx: ToolContext,
        events: Sender<AgentEvent>,
        commands: Receiver<Command>,
    ) -> Self {
        let mut agent = Self {
            llm,
            model: options.model.clone().unwrap_or_default(),
            options,
            messages: vec![],
            ctx,
            log: SessionLog::disabled(),
            events,
            commands,
            online: false,
            quit: Cell::new(false),
        };
        agent.reset();
        agent
    }

    /// Handle commands until Quit. Returns the final history.
    pub fn run(mut self) -> Vec<Message> {
        self.connect();
        while let Ok(command) = self.commands.recv() {
            match command {
                Command::Submit(text) => self.user_turn(text),
                Command::UserShell(command) => self.user_shell(command),
                Command::NewSession => self.reset(),
                Command::Quit => break,
                // Only meaningful while busy; stale ones are dropped.
                Command::Approve | Command::Deny(_) | Command::Interrupt => continue,
            }
            if self.quit.get() {
                break;
            }
            self.emit(AgentEvent::Idle);
        }
        self.messages
    }

    fn emit(&self, event: AgentEvent) {
        // If the UI is gone there is nobody to tell.
        let _ = self.events.send(event);
    }

    /// Fresh history (re-reading AGENTS.md) and fresh log files.
    fn reset(&mut self) {
        let agents_md = crate::prompt::load_agents_md(&self.ctx.project_root);
        let prompt = crate::prompt::system_prompt(&self.ctx.cwd, &crate::time::today(), agents_md.as_deref());
        self.messages = vec![Message::System { content: prompt }];
        self.log = if self.options.log {
            SessionLog::create(&self.ctx.project_root, &crate::time::file_stamp())
                .unwrap_or_else(|_| SessionLog::disabled())
        } else {
            SessionLog::disabled()
        };
        if let Some(agents) = agents_md {
            self.log.md(&format!("## AGENTS.md\n\n{agents}\n"));
            self.emit(AgentEvent::Info(format!("loaded AGENTS.md ({} lines)", agents.lines().count())));
        }
    }

    /// Ask the server for its model and context size; report the result.
    fn connect(&mut self) -> bool {
        let probe = self.llm.probe();
        self.online = probe.is_ok();
        let n_ctx = match probe {
            Ok((model, n_ctx)) => {
                if self.options.model.is_none() {
                    self.model = model;
                }
                n_ctx
            }
            Err(_) => 0,
        };
        self.emit(AgentEvent::ServerStatus { online: self.online, model: self.model.clone(), n_ctx });
        self.online
    }

    /// Add a user message, merging with a preceding user message (e.g. from
    /// a `!command`) so roles keep alternating.
    fn push_user(&mut self, text: String) {
        if let Some(Message::User { content }) = self.messages.last_mut() {
            content.push_str("\n\n");
            content.push_str(&text);
        } else {
            self.messages.push(Message::User { content: text });
        }
    }

    fn user_turn(&mut self, text: String) {
        if self.model.is_empty() && !self.connect() {
            self.emit(AgentEvent::Error("server offline".into()));
            self.emit(AgentEvent::RestoreInput(text));
            return;
        }
        let before = self.messages.clone();
        self.log.md(&format!("## User\n\n{text}\n"));
        self.push_user(text.clone());

        let mut steps = 0;
        let mut first_request = true;
        loop {
            if steps == self.options.max_steps {
                if !self.ask_continue(steps) {
                    self.emit(AgentEvent::TurnDone { usage: None, tokens_per_sec: None, interrupted: false });
                    return;
                }
                steps = 0;
            }
            steps += 1;

            let request = chat_request(&self.model, &self.messages, &tools::definitions());
            let (result, interrupted) = self.stream(&request);
            let (completion, interrupted) = match result {
                Err(e) => {
                    if matches!(e, LlmError::Offline(_)) {
                        self.online = false;
                        self.emit(AgentEvent::ServerStatus {
                            online: false,
                            model: self.model.clone(),
                            n_ctx: 0,
                        });
                    }
                    self.log.md(&format!("**Error:** {e}\n"));
                    self.emit(AgentEvent::Error(e.to_string()));
                    if first_request {
                        // Nothing happened; put the history and the input back.
                        self.messages = before;
                        self.emit(AgentEvent::RestoreInput(text));
                    }
                    return;
                }
                Ok(Streamed::Aborted(c)) => (c, true),
                Ok(Streamed::Complete(c)) => (c, interrupted),
            };
            first_request = false;
            if !self.online {
                self.connect(); // the server is back; refresh the status line
            }
            self.record_wire(&request, &completion);
            self.log_completion(&completion);

            if interrupted {
                // Keep what the model said; drop half-formed tool calls.
                if !completion.content.is_empty() {
                    self.messages
                        .push(Message::Assistant { content: completion.content, tool_calls: vec![] });
                }
                self.log.md("_[interrupted]_\n");
                self.emit(AgentEvent::TurnDone {
                    usage: completion.usage,
                    tokens_per_sec: completion.tokens_per_sec,
                    interrupted: true,
                });
                return;
            }

            let calls = completion.tool_calls.clone();
            self.messages.push(Message::Assistant { content: completion.content, tool_calls: calls.clone() });
            if calls.is_empty() {
                self.emit(AgentEvent::TurnDone {
                    usage: completion.usage,
                    tokens_per_sec: completion.tokens_per_sec,
                    interrupted: false,
                });
                return;
            }

            for (i, call) in calls.iter().enumerate() {
                let (status, content) = self.run_call(call);
                self.messages.push(Message::Tool { tool_call_id: call.id.clone(), content });
                if status == ToolStatus::Cancelled {
                    for rest in &calls[i + 1..] {
                        self.cancel_call(rest);
                    }
                    self.emit(AgentEvent::TurnDone {
                        usage: completion.usage,
                        tokens_per_sec: completion.tokens_per_sec,
                        interrupted: true,
                    });
                    return;
                }
            }
        }
    }

    /// True if an Interrupt (or Quit) is waiting. Non-blocking.
    fn interrupt_pending(commands: &Receiver<Command>, quit: &Cell<bool>) -> bool {
        match commands.try_recv() {
            Ok(Command::Interrupt) => true,
            Ok(Command::Quit) => {
                quit.set(true);
                true
            }
            _ => false,
        }
    }

    /// Stream one completion, forwarding deltas to the UI.
    /// Returns the result and whether the user interrupted.
    fn stream(&self, request: &Value) -> (Result<Streamed, LlmError>, bool) {
        let events = &self.events;
        let commands = &self.commands;
        let quit = &self.quit;
        let mut interrupted = false;
        let result = self.llm.stream(request, &mut |delta| {
            if Self::interrupt_pending(commands, quit) {
                interrupted = true;
                return false;
            }
            let event = match delta {
                Delta::Reasoning(r) => AgentEvent::ReasoningDelta(r),
                Delta::Text(t) => AgentEvent::TextDelta(t),
            };
            let _ = events.send(event);
            true
        });
        (result, interrupted)
    }

    fn run_call(&mut self, call: &ToolCall) -> (ToolStatus, String) {
        let id = call.id.clone();
        let name = call.function.name.clone();
        let args = call.function.arguments.clone();
        let summary = tools::summarize(&name, &args);
        self.emit(AgentEvent::ToolCallParsed { id: id.clone(), name, summary: summary.clone() });
        self.log.md(&format!("### Tool call: {summary}\n\n```json\n{args}\n```\n"));

        let (status, content) = match tools::prepare(&call.function.name, &args, &self.ctx) {
            Prepared::Failed(msg) => (ToolStatus::Error, format!("Error: {msg}")),
            Prepared::Ready(action) => self.execute(&id, &action),
            Prepared::NeedsApproval(request, action) => {
                self.log.md(&format!("Approval requested:\n\n```\n{}\n```\n", request.body));
                match self.ask(request) {
                    Decision::Approve => {
                        self.log.md("**Approved.**\n");
                        self.execute(&id, &action)
                    }
                    Decision::Deny(None) => (ToolStatus::Denied, "Denied by user.".to_string()),
                    Decision::Deny(Some(reason)) => (ToolStatus::Denied, format!("Denied by user: {reason}")),
                    Decision::Interrupt => (ToolStatus::Cancelled, "Cancelled by user.".to_string()),
                }
            }
        };
        self.log.md(&format!("Result ({status:?}):\n\n```\n{content}\n```\n"));
        self.emit(AgentEvent::ToolResult { id, status, content: content.clone() });
        (status, content)
    }

    /// Give an unrun call its "Cancelled" result.
    fn cancel_call(&mut self, call: &ToolCall) {
        let content = "Cancelled by user.".to_string();
        let summary = tools::summarize(&call.function.name, &call.function.arguments);
        self.emit(AgentEvent::ToolCallParsed {
            id: call.id.clone(),
            name: call.function.name.clone(),
            summary,
        });
        self.emit(AgentEvent::ToolResult {
            id: call.id.clone(),
            status: ToolStatus::Cancelled,
            content: content.clone(),
        });
        self.messages.push(Message::Tool { tool_call_id: call.id.clone(), content });
    }

    fn execute(&self, id: &str, action: &Action) -> (ToolStatus, String) {
        let events = &self.events;
        let commands = &self.commands;
        let quit = &self.quit;
        tools::execute(
            action,
            &self.ctx,
            &mut |line| {
                let _ = events.send(AgentEvent::ToolOutput { id: id.to_string(), line: line.to_string() });
            },
            &mut || Self::interrupt_pending(commands, quit),
        )
    }

    /// Show an approval request and block until the user decides.
    fn ask(&self, request: ApprovalRequest) -> Decision {
        self.emit(AgentEvent::ApprovalNeeded(request));
        loop {
            match self.commands.recv() {
                Ok(Command::Approve) => return Decision::Approve,
                Ok(Command::Deny(reason)) => return Decision::Deny(reason),
                Ok(Command::Interrupt) => return Decision::Interrupt,
                Ok(Command::Quit) | Err(_) => {
                    self.quit.set(true);
                    return Decision::Interrupt;
                }
                Ok(_) => continue,
            }
        }
    }

    fn ask_continue(&self, steps: usize) -> bool {
        let request = ApprovalRequest {
            title: "Continue?".into(),
            subject: String::new(),
            body: format!(
                "The model has made {steps} requests for this message.\n\
                 Approve to allow {} more; deny to stop here.",
                self.options.max_steps
            ),
            outside_project: false,
            overwrite: false,
        };
        matches!(self.ask(request), Decision::Approve)
    }

    /// Handle `!command`: run it, or change directory for a bare `!cd`.
    fn user_shell(&mut self, command: String) {
        if let Some(dir) = parse_cd(&command) {
            let target = paths::resolve(&self.ctx.cwd, dir);
            if !target.is_dir() {
                let output = format!("cd: no such directory: {}", target.display());
                self.emit(AgentEvent::ShellResult { command, output });
                return;
            }
            self.ctx.cwd = target.clone();
            let note = format!("Working directory is now {}", target.display());
            self.log.md(&format!("_{note}_\n"));
            self.push_user(note);
            self.emit(AgentEvent::CwdChanged(target));
            return;
        }

        let output = match guard::check_command(&command) {
            Err(msg) => format!("Error: {msg}"),
            Ok(()) => {
                let events = &self.events;
                let commands = &self.commands;
                let quit = &self.quit;
                let result = bash::run(
                    &command,
                    &self.ctx.cwd,
                    &self.ctx.shim_dir,
                    bash::DEFAULT_TIMEOUT,
                    &mut |line| {
                        let _ =
                            events.send(AgentEvent::ToolOutput { id: "!".into(), line: line.to_string() });
                    },
                    &mut || Self::interrupt_pending(commands, quit),
                );
                match result {
                    Ok(r) => r.for_model(),
                    Err(e) => format!("Error: could not run bash: {e}"),
                }
            }
        };
        let message =
            format!("I ran this command in {}:\n$ {command}\n```\n{output}\n```", self.ctx.cwd.display());
        self.log.md(&format!("## User shell\n\n{message}\n"));
        self.push_user(message);
        self.emit(AgentEvent::ShellResult { command, output });
    }

    fn record_wire(&mut self, request: &Value, c: &Completion) {
        let mut record = json!({
            "request": request,
            "response": {
                "content": c.content,
                "reasoning": c.reasoning,
                "tool_calls": c.tool_calls,
                "finish_reason": c.finish_reason,
                "usage": c.usage,
                "tokens_per_sec": c.tokens_per_sec,
            },
        });
        let raw = self.llm.take_raw();
        if !raw.is_empty() {
            record["raw"] = json!(raw);
        }
        self.log.wire(&record);
        self.emit(AgentEvent::Wire(serde_json::to_string_pretty(&record).unwrap_or_default()));
    }

    fn log_completion(&mut self, c: &Completion) {
        if !c.reasoning.is_empty() {
            self.log.md(&format!("### Thinking\n\n{}\n", c.reasoning));
        }
        if !c.content.is_empty() {
            self.log.md(&format!("## Assistant\n\n{}\n", c.content));
        }
    }
}

/// If `command` is a bare `cd [dir]`, return the directory (`~` if none).
/// Anything more complex (`cd a && make`, quoting, variables) returns None
/// and runs as a normal command.
pub fn parse_cd(command: &str) -> Option<&str> {
    let rest = command.trim().strip_prefix("cd")?;
    if !rest.is_empty() && !rest.starts_with(char::is_whitespace) {
        return None; // e.g. "cdk"
    }
    let arg = rest.trim();
    if arg.is_empty() {
        return Some("~");
    }
    if arg.contains(|c: char| c.is_whitespace() || ";&|<>$`'\"(){}*?".contains(c)) {
        return None;
    }
    Some(arg)
}
````

````rust
//! A small multi-line text editor with emacs/readline keys.
//!
//! The text is a flat `Vec<char>` with newlines in it, and the cursor is an
//! index into it. Lines are computed on demand; that keeps every motion a
//! simple scan.

use ratatui::crossterm::event::{KeyCode, KeyEvent, KeyModifiers};

#[derive(Debug, Default, Clone)]
pub struct Editor {
    chars: Vec<char>,
    cursor: usize,
    /// Single-slot kill buffer for Ctrl-Y.
    kill: String,
}

impl Editor {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn text(&self) -> String {
        self.chars.iter().collect()
    }

    pub fn is_empty(&self) -> bool {
        self.chars.is_empty()
    }

    /// Clear the text (the kill buffer survives).
    pub fn clear(&mut self) {
        self.chars.clear();
        self.cursor = 0;
    }

    /// Replace the text; cursor goes to the end.
    pub fn set_text(&mut self, text: &str) {
        self.chars = text.chars().collect();
        self.cursor = self.chars.len();
    }

    /// (row, column) of the cursor.
    pub fn cursor_pos(&self) -> (usize, usize) {
        let row = self.chars[..self.cursor].iter().filter(|&&c| c == '\n').count();
        (row, self.cursor - self.line_start())
    }

    pub fn lines(&self) -> Vec<String> {
        self.text().split('\n').map(str::to_string).collect()
    }

    pub fn insert_str(&mut self, s: &str) {
        for c in s.chars() {
            self.chars.insert(self.cursor, c);
            self.cursor += 1;
        }
    }

    fn line_start(&self) -> usize {
        self.chars[..self.cursor].iter().rposition(|&c| c == '\n').map_or(0, |i| i + 1)
    }

    fn line_end(&self) -> usize {
        self.chars[self.cursor..]
            .iter()
            .position(|&c| c == '\n')
            .map_or(self.chars.len(), |i| self.cursor + i)
    }

    fn word_forward_pos(&self) -> usize {
        let mut i = self.cursor;
        while i < self.chars.len() && self.chars[i].is_whitespace() {
            i += 1;
        }
        while i < self.chars.len() && !self.chars[i].is_whitespace() {
            i += 1;
        }
        i
    }

    fn word_backward_pos(&self) -> usize {
        let mut i = self.cursor;
        while i > 0 && self.chars[i - 1].is_whitespace() {
            i -= 1;
        }
        while i > 0 && !self.chars[i - 1].is_whitespace() {
            i -= 1;
        }
        i
    }

    /// Remove chars in `from..to`, saving them in the kill buffer.
    fn kill_range(&mut self, from: usize, to: usize) {
        if from < to {
            self.kill = self.chars.drain(from..to).collect();
            self.cursor = from;
        }
    }

    /// Move to the same column on another line (clamped to its length).
    fn move_line(&mut self, down: bool) {
        let col = self.cursor - self.line_start();
        let target_start = if down {
            let end = self.line_end();
            if end == self.chars.len() {
                return;
            }
            end + 1
        } else {
            let start = self.line_start();
            if start == 0 {
                return;
            }
            self.chars[..start - 1].iter().rposition(|&c| c == '\n').map_or(0, |i| i + 1)
        };
        self.cursor = target_start;
        let end = self.line_end();
        self.cursor = (target_start + col).min(end);
    }

    /// Apply an editing key. Returns false if the key isn't an editing key.
    pub fn handle_key(&mut self, key: KeyEvent) -> bool {
        let ctrl = key.modifiers.contains(KeyModifiers::CONTROL);
        let alt = key.modifiers.contains(KeyModifiers::ALT);
        match key.code {
            KeyCode::Char('f') if ctrl => self.cursor = (self.cursor + 1).min(self.chars.len()),
            KeyCode::Right => self.cursor = (self.cursor + 1).min(self.chars.len()),
            KeyCode::Char('b') if ctrl => self.cursor = self.cursor.saturating_sub(1),
            KeyCode::Left => self.cursor = self.cursor.saturating_sub(1),
            KeyCode::Char('f') if alt => self.cursor = self.word_forward_pos(),
            KeyCode::Char('b') if alt => self.cursor = self.word_backward_pos(),
            KeyCode::Char('a') if ctrl => self.cursor = self.line_start(),
            KeyCode::Home => self.cursor = self.line_start(),
            KeyCode::Char('e') if ctrl => self.cursor = self.line_end(),
            KeyCode::End => self.cursor = self.line_end(),
            KeyCode::Char('p') if ctrl => self.move_line(false),
            KeyCode::Up => self.move_line(false),
            KeyCode::Char('n') if ctrl => self.move_line(true),
            KeyCode::Down => self.move_line(true),
            KeyCode::Char('d') if ctrl => {
                if self.cursor < self.chars.len() {
                    self.chars.remove(self.cursor);
                }
            }
            KeyCode::Delete => {
                if self.cursor < self.chars.len() {
                    self.chars.remove(self.cursor);
                }
            }
            KeyCode::Backspace if alt => self.kill_range(self.word_backward_pos(), self.cursor),
            KeyCode::Char('h') if ctrl => self.backspace(),
            KeyCode::Backspace => self.backspace(),
            KeyCode::Char('d') if alt => self.kill_range(self.cursor, self.word_forward_pos()),
            KeyCode::Char('k') if ctrl => {
                let end = self.line_end();
                if end == self.cursor && end < self.chars.len() {
                    self.kill_range(self.cursor, end + 1); // at end of line: join
                } else {
                    self.kill_range(self.cursor, end);
                }
            }
            KeyCode::Char('u') if ctrl => self.kill_range(self.line_start(), self.cursor),
            KeyCode::Char('y') if ctrl => {
                let kill = self.kill.clone();
                self.insert_str(&kill);
            }
            KeyCode::Char(c) if !ctrl && !alt => self.insert_str(&c.to_string()),
            _ => return false,
        }
        true
    }

    fn backspace(&mut self) {
        if self.cursor > 0 {
            self.cursor -= 1;
            self.chars.remove(self.cursor);
        }
    }
}
````

````rust
//! UI state, updated from agent events.

use crate::events::{AgentEvent, ApprovalRequest, ToolStatus};
use crate::ui::editor::Editor;
use std::path::PathBuf;
use std::time::{Duration, Instant};

/// One visual element of the conversation.
#[derive(Debug, Clone, PartialEq)]
pub enum Block {
    User(String),
    /// A `!command`; `output` is None while it runs.
    Shell {
        command: String,
        live: Vec<String>,
        output: Option<String>,
    },
    /// Reasoning. `elapsed` is None while the model is still thinking.
    Thinking {
        text: String,
        started: Instant,
        elapsed: Option<Duration>,
    },
    Assistant(String),
    /// `status` is None while running.
    Tool {
        id: String,
        summary: String,
        status: Option<ToolStatus>,
        live: Vec<String>,
        result: String,
    },
    Info(String),
    Error(String),
}

/// An approval the user is looking at.
#[derive(Debug, Clone)]
pub struct Pending {
    pub request: ApprovalRequest,
    pub scroll: u16,
    /// Some while typing a deny reason.
    pub reason: Option<Editor>,
}

#[derive(Debug)]
pub struct App {
    pub blocks: Vec<Block>,
    pub input: Editor,
    /// The agent is working on something; Enter won't submit.
    pub busy: bool,
    pub pending: Option<Pending>,
    pub show_thinking: bool,
    pub show_tools: bool,
    /// Rows scrolled up from the bottom; 0 means following new output.
    pub scroll_back: usize,
    /// Height of the conversation pane at the last draw.
    pub view_height: u16,
    /// Pretty JSON of each model exchange, for the inspector.
    pub wire: Vec<String>,
    /// Some(scroll) while the wire inspector is open.
    pub wire_view: Option<u16>,
    /// Ctrl-X was pressed; waiting for the second key.
    pub ctrl_x: bool,
    /// Ctrl-C was pressed on an empty input; another quits.
    pub quit_armed: bool,
    pub quit: bool,
    pub model: String,
    pub online: bool,
    pub n_ctx: u64,
    pub ctx_used: u64,
    pub tokens_per_sec: Option<f64>,
    pub cwd: PathBuf,
    /// What the agent is doing, for the status line.
    pub activity: String,
}

impl App {
    pub fn new(cwd: PathBuf) -> Self {
        Self {
            blocks: vec![],
            input: Editor::new(),
            busy: false,
            pending: None,
            show_thinking: false,
            show_tools: false,
            scroll_back: 0,
            view_height: 0,
            wire: vec![],
            wire_view: None,
            ctrl_x: false,
            quit_armed: false,
            quit: false,
            model: String::new(),
            online: false,
            n_ctx: 0,
            ctx_used: 0,
            tokens_per_sec: None,
            cwd,
            activity: String::new(),
        }
    }

    fn tool_mut(&mut self, id: &str) -> Option<&mut Block> {
        self.blocks.iter_mut().rev().find(|b| matches!(b, Block::Tool { id: i, .. } if i == id))
    }

    fn running_shell(&mut self) -> Option<&mut Block> {
        self.blocks.iter_mut().rev().find(|b| matches!(b, Block::Shell { output: None, .. }))
    }

    /// Stop the clock on a thinking block that is still open.
    fn end_thinking(&mut self) {
        if let Some(Block::Thinking { started, elapsed: elapsed @ None, .. }) = self.blocks.last_mut() {
            *elapsed = Some(started.elapsed());
        }
    }

    pub fn on_agent_event(&mut self, event: AgentEvent) {
        // Anything other than more reasoning means the thinking has finished.
        if !matches!(event, AgentEvent::ReasoningDelta(_)) {
            self.end_thinking();
        }
        match event {
            AgentEvent::ServerStatus { online, model, n_ctx } => {
                self.online = online;
                self.model = model;
                if n_ctx > 0 {
                    self.n_ctx = n_ctx;
                }
            }
            AgentEvent::ReasoningDelta(t) => {
                self.activity = "thinking".into();
                match self.blocks.last_mut() {
                    Some(Block::Thinking { text, elapsed: None, .. }) => text.push_str(&t),
                    _ => {
                        self.blocks.push(Block::Thinking { text: t, started: Instant::now(), elapsed: None })
                    }
                }
            }
            AgentEvent::TextDelta(t) => {
                self.activity = "writing".into();
                match self.blocks.last_mut() {
                    Some(Block::Assistant(s)) => s.push_str(&t),
                    _ => self.blocks.push(Block::Assistant(t)),
                }
            }
            AgentEvent::ToolCallParsed { id, summary, .. } => {
                self.activity = format!("running {summary}");
                self.blocks.push(Block::Tool {
                    id,
                    summary,
                    status: None,
                    live: vec![],
                    result: String::new(),
                });
            }
            AgentEvent::ApprovalNeeded(request) => {
                self.activity = "waiting for approval".into();
                self.pending = Some(Pending { request, scroll: 0, reason: None });
            }
            AgentEvent::ToolOutput { id, line } => {
                let block = if id == "!" { self.running_shell() } else { self.tool_mut(&id) };
                match block {
                    Some(Block::Tool { live, .. }) | Some(Block::Shell { live, .. }) => live.push(line),
                    _ => {}
                }
            }
            AgentEvent::ToolResult { id, status, content } => {
                self.pending = None;
                if let Some(Block::Tool { status: s, result, .. }) = self.tool_mut(&id) {
                    *s = Some(status);
                    *result = content;
                }
            }
            AgentEvent::ShellResult { command, output } => {
                if let Some(Block::Shell { output: o, .. }) = self.running_shell() {
                    *o = Some(output);
                } else {
                    self.blocks.push(Block::Shell { command, live: vec![], output: Some(output) });
                }
            }
            AgentEvent::CwdChanged(dir) => {
                if matches!(self.blocks.last(), Some(Block::Shell { output: None, .. })) {
                    self.blocks.pop();
                }
                self.blocks.push(Block::Info(format!("working directory is now {}", dir.display())));
                self.cwd = dir;
            }
            AgentEvent::TurnDone { usage, tokens_per_sec, interrupted } => {
                if let Some(u) = usage {
                    self.ctx_used = u.total_tokens;
                }
                if tokens_per_sec.is_some() {
                    self.tokens_per_sec = tokens_per_sec;
                }
                if interrupted {
                    self.blocks.push(Block::Info("[interrupted]".into()));
                }
            }
            AgentEvent::RestoreInput(text) => {
                // The request never happened: take its message off the screen.
                if let Some(i) = self.blocks.iter().rposition(|b| *b == Block::User(text.clone())) {
                    self.blocks.remove(i);
                }
                self.input.set_text(&text);
            }
            AgentEvent::Wire(json) => self.wire.push(json),
            AgentEvent::Error(e) => self.blocks.push(Block::Error(e)),
            AgentEvent::Info(text) => self.blocks.push(Block::Info(text)),
            AgentEvent::Idle => {
                self.busy = false;
                self.pending = None;
                self.activity.clear();
            }
        }
    }
}
````

````rust
//! Keys → UI changes and Commands for the agent.

use crate::events::Command;
use crate::ui::app::{App, Block};
use crate::ui::editor::Editor;
use ratatui::crossterm::event::{KeyCode, KeyEvent, KeyModifiers};

pub fn handle_key(app: &mut App, key: KeyEvent) -> Option<Command> {
    let ctrl = key.modifiers.contains(KeyModifiers::CONTROL);
    let alt = key.modifiers.contains(KeyModifiers::ALT);

    if let Some(scroll) = app.wire_view.as_mut() {
        match key.code {
            KeyCode::Esc | KeyCode::Char('q') => app.wire_view = None,
            KeyCode::Char('j') | KeyCode::Down => *scroll = scroll.saturating_add(1),
            KeyCode::Char('k') | KeyCode::Up => *scroll = scroll.saturating_sub(1),
            KeyCode::PageDown | KeyCode::Char(' ') => *scroll = scroll.saturating_add(20),
            KeyCode::PageUp => *scroll = scroll.saturating_sub(20),
            _ => {}
        }
        return None;
    }

    if app.pending.is_some() {
        return approval_key(app, key, ctrl);
    }

    if app.ctrl_x {
        app.ctrl_x = false;
        match key.code {
            KeyCode::Char('o') => app.show_tools = !app.show_tools,
            KeyCode::Char('t') => app.show_thinking = !app.show_thinking,
            KeyCode::Char('w') => app.wire_view = Some(0),
            _ => {}
        }
        return None;
    }

    let is_ctrl_c = ctrl && key.code == KeyCode::Char('c');
    if !is_ctrl_c {
        app.quit_armed = false;
    }
    let half = (app.view_height / 2).max(1) as usize;
    let page = app.view_height.max(1) as usize;
    match key.code {
        KeyCode::Char('c') if ctrl => {
            if app.busy {
                return Some(Command::Interrupt);
            }
            if !app.input.is_empty() {
                app.input.clear();
            } else if app.quit_armed {
                app.quit = true;
                return Some(Command::Quit);
            } else {
                app.quit_armed = true;
            }
        }
        KeyCode::Char('x') if ctrl => app.ctrl_x = true,
        KeyCode::Char('v') if ctrl => app.scroll_back = app.scroll_back.saturating_sub(half),
        KeyCode::Char('v') if alt => app.scroll_back += half,
        KeyCode::PageDown => app.scroll_back = app.scroll_back.saturating_sub(page),
        KeyCode::PageUp => app.scroll_back += page,
        KeyCode::Enter if alt => app.input.insert_str("\n"),
        KeyCode::Char('j') if ctrl => app.input.insert_str("\n"),
        KeyCode::Enter => return submit(app),
        _ => {
            app.input.handle_key(key);
        }
    }
    None
}

/// Bracketed paste: insert text (newlines included) without submitting.
pub fn handle_paste(app: &mut App, text: &str) {
    let text = text.replace("\r\n", "\n").replace('\r', "\n");
    match app.pending.as_mut() {
        // While typing a deny reason, paste into it (as one line).
        Some(p) => {
            if let Some(reason) = p.reason.as_mut() {
                reason.insert_str(&text.replace('\n', " "));
            }
        }
        None if app.wire_view.is_none() => app.input.insert_str(&text),
        None => {}
    }
}

fn approval_key(app: &mut App, key: KeyEvent, ctrl: bool) -> Option<Command> {
    let pending = app.pending.as_mut()?;
    if let Some(reason) = pending.reason.as_mut() {
        match key.code {
            KeyCode::Enter => {
                let text = reason.text().trim().to_string();
                app.pending = None;
                return Some(Command::Deny(if text.is_empty() { None } else { Some(text) }));
            }
            KeyCode::Esc => pending.reason = None,
            _ => {
                reason.handle_key(key);
            }
        }
        return None;
    }
    match key.code {
        KeyCode::Char('y') => {
            app.pending = None;
            Some(Command::Approve)
        }
        KeyCode::Char('n') => {
            app.pending = None;
            Some(Command::Deny(None))
        }
        KeyCode::Char('c') if ctrl => {
            app.pending = None;
            Some(Command::Interrupt)
        }
        KeyCode::Char('r') => {
            pending.reason = Some(Editor::new());
            None
        }
        KeyCode::Char('j') | KeyCode::Down => {
            pending.scroll = pending.scroll.saturating_add(1);
            None
        }
        KeyCode::Char('k') | KeyCode::Up => {
            pending.scroll = pending.scroll.saturating_sub(1);
            None
        }
        KeyCode::PageDown => {
            pending.scroll = pending.scroll.saturating_add(10);
            None
        }
        KeyCode::PageUp => {
            pending.scroll = pending.scroll.saturating_sub(10);
            None
        }
        _ => None,
    }
}

fn submit(app: &mut App) -> Option<Command> {
    if app.busy {
        return None;
    }
    let text = app.input.text();
    let trimmed = text.trim();
    if trimmed.is_empty() {
        return None;
    }
    app.scroll_back = 0;
    if let Some(cmd) = trimmed.strip_prefix('/') {
        app.input.clear();
        return match cmd {
            "new" => {
                app.blocks.clear();
                app.wire.clear();
                app.ctx_used = 0;
                app.busy = true;
                Some(Command::NewSession)
            }
            "quit" => {
                app.quit = true;
                Some(Command::Quit)
            }
            other => {
                app.blocks.push(Block::Info(format!("unknown command /{other} (try /new or /quit)")));
                None
            }
        };
    }
    if let Some(cmd) = trimmed.strip_prefix('!') {
        let cmd = cmd.trim().to_string();
        if cmd.is_empty() {
            return None;
        }
        app.input.clear();
        app.busy = true;
        app.activity = format!("running !{cmd}");
        app.blocks.push(Block::Shell { command: cmd.clone(), live: vec![], output: None });
        return Some(Command::UserShell(cmd));
    }
    app.input.clear();
    app.busy = true;
    app.activity = "waiting for model".into();
    app.blocks.push(Block::User(text.clone()));
    Some(Command::Submit(text))
}
````

}

/// The whole conversation as styled lines (before wrapping).
pub fn conversation_lines(app: &App) -> Vec<Line<'static>> {
    let mut out: Vec<Line<'static>> = vec![];
    for block in &app.blocks {
        match block {
            Block::User(text) => {
                for (j, l) in text.lines().enumerate() {
                    let prefix = if j == 0 { "› " } else { "  " };
                    out.push(Line::from(vec![
                        Span::styled(prefix, Style::default().fg(Color::Cyan).bold()),
                        Span::raw(l.to_string()).bold(),
                    ]));
                }
            }
            Block::Shell { command, live, output } => {
                out.push(Line::styled(format!("! {command}"), Style::default().fg(Color::Yellow).bold()));
                match output {
                    None => tail_lines(live, &mut out),
                    Some(o) => {
                        let lines: Vec<String> = o.lines().map(str::to_string).collect();
                        if app.show_tools {
                            lines.iter().for_each(|l| out.push(Line::styled(format!("│ {l}"), dim())));
                        } else {
                            tail_lines(&lines, &mut out);
                        }
                    }
                }
            }
            Block::Thinking { text, started, elapsed } => {
                // One line with a timer; the text itself only when toggled on.
                let label = match elapsed {
                    Some(d) => format!("thought for {}s", d.as_secs()),
                    None => format!("thinking… {}s", started.elapsed().as_secs()),
                };
                let arrow = if app.show_thinking { "▾" } else { "▸" };
                out.push(Line::styled(format!("{arrow} {label}"), dim()));
                if app.show_thinking {
                    for l in text.lines() {
                        out.push(Line::styled(l.to_string(), dim().add_modifier(Modifier::ITALIC)));
                    }
                }
            }
            Block::Assistant(text) => {
                let mut in_code = false;
                for l in text.lines() {
                    let fence = l.trim_start().starts_with("```");
                    if fence {
                        in_code = !in_code;
                    }
                    if in_code || fence {
                        out.push(Line::styled(l.to_string(), Style::default().fg(Color::Green)));
                    } else {
                        out.push(Line::raw(l.to_string()));
                    }
                }
            }
            Block::Tool { summary, status, live, result, .. } => {
                let (icon, color) = match status {
                    None => ("⏳", Color::Yellow),
                    Some(ToolStatus::Ok) => ("✓", Color::Green),
                    Some(ToolStatus::Error) => ("✗", Color::Red),
                    Some(ToolStatus::Denied) => ("⊘", Color::Magenta),
                    Some(ToolStatus::Cancelled) => ("⊘", Color::DarkGray),
                };
                let n = result.lines().count();
                let suffix = if status.is_some() && !app.show_tools && n > 0 {
                    format!("  ({n} lines)")
                } else {
                    String::new()
                };
                out.push(Line::from(vec![
                    Span::styled(format!("{icon} "), Style::default().fg(color)),
                    Span::raw(summary.clone()).bold(),
                    Span::styled(suffix, dim()),
                ]));
                match status {
                    None => tail_lines(live, &mut out),
                    Some(_) if app.show_tools => {
                        result.lines().for_each(|l| out.push(Line::styled(format!("│ {l}"), dim())));
                    }
                    // Collapsed: show only failures' first line, so errors stay visible.
                    Some(ToolStatus::Error) | Some(ToolStatus::Denied) => {
                        if let Some(l) = result.lines().next() {
                            out.push(Line::styled(format!("│ {l}"), Style::default().fg(color)));
                        }
                    }
                    Some(_) => {}
                }
            }
            Block::Info(text) => out.push(Line::styled(text.clone(), dim())),
            Block::Error(text) => {
                out.push(Line::styled(format!("✗ {text}"), Style::default().fg(Color::Red)))
            }
        }
        out.push(Line::raw(""));
    }
    out
}

fn draw_conversation(f: &mut Frame, app: &mut App, area: Rect) {
    app.view_height = area.height;
    let lines = conversation_lines(app);
    // Rows each line occupies once wrapped to the pane width.
    let heights: Vec<usize> = lines
        .iter()
        .map(|l| Paragraph::new(l.clone()).wrap(Wrap { trim: false }).line_count(area.width).max(1))
        .collect();
    let total: usize = heights.iter().sum();
    let height = area.height as usize;
    let max_back = total.saturating_sub(height);
    app.scroll_back = app.scroll_back.min(max_back);
    let top_row = total.saturating_sub(height + app.scroll_back);

    // Skip whole lines above the view; scroll the remainder within the first line.
    let mut first = 0;
    let mut row = 0;
    while first < lines.len() && row + heights[first] <= top_row {
        row += heights[first];
        first += 1;
    }
    let offset = (top_row - row) as u16;
    let visible: Vec<Line> = lines.into_iter().skip(first).collect();
    f.render_widget(Paragraph::new(visible).wrap(Wrap { trim: false }).scroll((offset, 0)), area);
}

fn draw_input(f: &mut Frame, app: &App, area: Rect) {
    let title = if app.busy { " working… Ctrl-C interrupts " } else { "" };
    let frame = Frame_::default().borders(Borders::TOP).title(title).border_style(dim());
    let inner = frame.inner(area);
    f.render_widget(frame, area);

    let (row, col) = app.input.cursor_pos();
    let first = row.saturating_sub(INPUT_LINES - 1);
    let lines: Vec<Line> = app
        .input
        .lines()
        .into_iter()
        .enumerate()
        .skip(first)
        .map(|(i, l)| Line::raw(format!("{}{l}", if i == 0 { "> " } else { "  " })))
        .collect();
    f.render_widget(Paragraph::new(lines), inner);
    if app.pending.is_none() && app.wire_view.is_none() {
        f.set_cursor_position(Position::new(inner.x + 2 + col as u16, inner.y + (row - first) as u16));
    }
}

fn draw_status(f: &mut Frame, app: &App, area: Rect) {
    let mut spans = vec![];
    if app.online {
        let model = app.model.rsplit('/').next().unwrap_or(&app.model).trim_end_matches(".gguf");
        spans.push(Span::raw(format!(" {model}")));
    } else {
        spans.push(Span::styled(" server offline", Style::default().fg(Color::Red)));
    }
    spans.push(Span::styled(format!(" · ctx {}/{}", kilo(app.ctx_used), kilo(app.n_ctx)), dim()));
    if let Some(tps) = app.tokens_per_sec {
        spans.push(Span::styled(format!(" · {tps:.0} tok/s"), dim()));
    }
    if !app.activity.is_empty() {
        spans.push(Span::styled(format!(" · {}", app.activity), Style::default().fg(Color::Yellow)));
    }
    if app.ctrl_x {
        spans.push(Span::styled("  C-x-", Style::default().bold()));
    } else if app.quit_armed {
        spans.push(Span::styled("  Ctrl-C again to quit", Style::default().bold()));
    }
    f.render_widget(Paragraph::new(Line::from(spans)), area);
}

fn kilo(n: u64) -> String {
    if n >= 1000 { format!("{:.1}k", n as f64 / 1000.0) } else { n.to_string() }
}

fn centered(area: Rect, pct_w: u16, pct_h: u16) -> Rect {

    let h = area.height * pct_h / 100;

}

    }

    }
    let frame = Frame_::default().borders(Borders::ALL).title(Line::from(title));
    let inner = frame.inner(area);
    f.render_widget(frame, area);
    let [body, footer] = Layout::vertical([Constraint::Min(1), Constraint::Length(1)]).areas(inner);

    let is_diff = p.request.body.starts_with("--- ");
    let lines: Vec<Line> = p
        .request
        .body
        .lines()
        .map(|l| {
            let style = if !is_diff {
                Style::default()
            } else if l.starts_with("@@") {
                Style::default().fg(Color::Cyan)
            } else if l.starts_with('+') {
                Style::default().fg(Color::Green)
            } else if l.starts_with('-') {
                Style::default().fg(Color::Red)
            } else {
                Style::default()
            };
            Line::styled(l.to_string(), style)
        })
        .collect();
    f.render_widget(Paragraph::new(lines).scroll((p.scroll, 0)), body);

    match &p.reason {
        None => f.render_widget(
            Paragraph::new(" [y] approve   [n] deny   [r] deny with reason   (j/k scroll)").bold(),
            footer,
        ),
        Some(reason) => {
            let text = reason.text();
            f.render_widget(Paragraph::new(format!(" reason: {text}")), footer);
            let col = reason.cursor_pos().1 as u16;
            f.set_cursor_position(Position::new(footer.x + 9 + col, footer.y));
        }
    }
}

        lines.extend(w.lines().map(|l| Line::raw(l.to_string())));

    let scroll = app.wire_view.unwrap_or(0);
    f.render_widget(
        Paragraph::new(lines).scroll((scroll, 0)).block(Frame_::default().borders(Borders::ALL).title(title)),
        area,
    );
}

````bash
#!/usr/bin/env bash
# End-to-end smoke test. Drives bridle in a detached tmux session against a
# running llama-server, the way a person would: type, approve, deny, interrupt.
#
# Usage: scripts/smoke.sh [bridle flags, e.g. --url http://127.0.0.1:9931]
# Needs: bash, tmux, python3 (for the file the model writes), a live server.
set -euo pipefail

root="$(cd "$(dirname "$0")/.." && pwd)"
cargo build --quiet --manifest-path "$root/Cargo.toml"
bin="$root/target/debug/bridle"

work="$(mktemp -d)"
session="bridle-smoke-$$"
cleanup() {
    tmux kill-session -t "$session" 2>/dev/null || true
    rm -rf "$work"
}
trap cleanup EXIT

screen() { tmux capture-pane -t "$session" -p; }
keys() { tmux send-keys -t "$session" "$@"; }
type_line() { keys -l "$1"; keys Enter; }
transcript() { cat "$work"/.bridle/sessions/*.md 2>/dev/null || true; }
fail() {
    echo "FAIL: $1"
    echo "--- screen ---"; screen
    echo "--- transcript ---"; transcript
    exit 1
}
# wait_for SECONDS DESCRIPTION COMMAND... : poll until COMMAND succeeds.
wait_for() {
    local secs=$1 what=$2; shift 2
    for _ in $(seq 1 $((secs * 2))); do
        if "$@"; then return 0; fi
        sleep 0.5
    done
    fail "timed out after ${secs}s waiting for: $what"
}
on_screen() { screen | grep -qF -- "$1"; }
in_transcript() { transcript | grep -qF -- "$1"; }
idle() { ! on_screen "working…"; }
# Approve every request until the agent goes idle.
approve_until_idle() {
    for _ in $(seq 1 360); do
        if on_screen "[y] approve"; then keys y; sleep 1; continue; fi
        if idle; then return 0; fi
        sleep 0.5
    done
    fail "agent never went idle"
}

echo 'Answer as briefly as possible.' > "$work/AGENTS.md"
tmux new-session -d -s "$session" -x 120 -y 40 -c "$work" "$bin $*"

echo "== starts, connects, loads AGENTS.md"
wait_for 15 "status line" on_screen "· ctx "
wait_for 15 "AGENTS.md notice" on_screen "loaded AGENTS.md (1 lines)"
on_screen "server offline" && fail "server offline"

echo "== !command output goes into the conversation"
type_line '!echo smoke-ok'
wait_for 10 "shell output" on_screen "│ smoke-ok"
wait_for 10 "idle" idle

echo "== model writes a file and runs it (approving each step)"
type_line "Create hello.py that prints 'hello from bridle', then run it with python3."
sleep 1
approve_until_idle
[ -f "$work/hello.py" ] || fail "hello.py was not created"
wait_for 5 "run result in transcript" in_transcript "hello from bridle"

echo "== deny with a reason reaches the model"
type_line "Use bash to run: ls -la"
wait_for 120 "approval prompt" on_screen "[y] approve"
keys r
type_line "not now"
wait_for 10 "denial in transcript" in_transcript "Denied by user: not now"
approve_until_idle

echo "== interrupting a running command"
type_line "Use bash to run: sleep 60"
wait_for 120 "approval prompt" on_screen "[y] approve"
keys y
sleep 2
keys C-c
wait_for 10 "interrupted" on_screen "[interrupted]"
wait_for 10 "idle" idle

echo "== reasoning stays hidden"
on_screen "▸ thought for" || fail "no collapsed thinking line"

echo "== quit"
````

````rust
//! Wiring: flags, the agent thread, and the terminal event loop.

use bridle::agent::{Agent, AgentOptions, DEFAULT_MAX_STEPS};
use bridle::config;
use bridle::events::{AgentEvent, Command};
use bridle::llm::client::LlamaClient;
use bridle::tools::{ToolContext, guard};
use bridle::ui::{app::App, input, render};
use ratatui::DefaultTerminal;
use ratatui::crossterm::event::{self, DisableBracketedPaste, EnableBracketedPaste, Event, KeyEventKind};
use ratatui::crossterm::execute;
use std::sync::mpsc::{Receiver, Sender, channel};
use std::time::{Duration, Instant};

fn main() -> anyhow::Result<()> {
    let config = match config::parse(std::env::args().skip(1)) {
        Ok(Some(c)) => c,
        Ok(None) => {
            println!("{}", config::USAGE);
            return Ok(());
        }
        Err(e) => {
            eprintln!("bridle: {e}\n\n{}", config::USAGE);
            std::process::exit(2);
        }
    };

    let root = std::env::current_dir()?;
    let shim_dir = guard::make_shim_dir()?;
    let ctx = ToolContext { cwd: root.clone(), project_root: root.clone(), shim_dir: shim_dir.clone() };

    let (cmd_tx, cmd_rx) = channel();
    let (ev_tx, ev_rx) = channel();
    let llm = LlamaClient::new(&config.url, config.wire_raw);
    let options = AgentOptions { model: config.model, log: true, max_steps: DEFAULT_MAX_STEPS };
    let agent = Agent::new(llm, options, ctx, ev_tx, cmd_rx);
    let agent_thread = std::thread::spawn(move || agent.run());

    let mut app = App::new(root);
    let mut terminal = ratatui::init(); // also installs a panic hook that restores the terminal
    execute!(std::io::stdout(), EnableBracketedPaste)?;
    let result = run_ui(&mut terminal, &mut app, &cmd_tx, &ev_rx);
    let _ = execute!(std::io::stdout(), DisableBracketedPaste);
    ratatui::restore();

    // Stop whatever is running (e.g. kill a bash process group), then quit.
    let _ = cmd_tx.send(Command::Interrupt);
    let _ = cmd_tx.send(Command::Quit);
    let deadline = Instant::now() + Duration::from_secs(1);
    while !agent_thread.is_finished() && Instant::now() < deadline {
        std::thread::sleep(Duration::from_millis(20));
    }
    let _ = std::fs::remove_dir_all(shim_dir);
    result
}

fn run_ui(
    terminal: &mut DefaultTerminal,
    app: &mut App,
    commands: &Sender<Command>,
    events: &Receiver<AgentEvent>,
) -> anyhow::Result<()> {
    loop {
        terminal.draw(|f| render::draw(f, app))?;
        if event::poll(Duration::from_millis(30))? {
            match event::read()? {
                Event::Key(key) if key.kind == KeyEventKind::Press => {
                    if let Some(command) = input::handle_key(app, key) {
                        let _ = commands.send(command);
                    }
                }
                Event::Paste(text) => input::handle_paste(app, &text),
                _ => {}
            }
        }
        while let Ok(event) = events.try_recv() {
            app.on_agent_event(event);
        }
        if app.quit {
            return Ok(());
        }
    }
}
````

`README.md`:

````markdown
# bridle

A minimal terminal coding harness for local models served by llama.cpp's
`llama-server`. Four tools (read, bash, edit, write), one agent loop, and
nothing hidden: every request and response is logged.

Runs on macOS and Linux.

## Running

Start llama-server with tool-calling templates enabled:

    llama-server -m <model.gguf> --jinja --port 9931

Then, in the project you want to work on:

    bridle [--url http://127.0.0.1:9931] [--model ID] [--wire-raw]

- `--url` — server base URL (default `http://127.0.0.1:9931`)
- `--model` — model id to request (default: the server's first model)
- `--wire-raw` — also log every raw SSE line

Install with `cargo install --path .` from this repository.

## AGENTS.md

If the directory you launch bridle in has an `AGENTS.md`, it is appended to
the system prompt as project instructions (read at start and on `/new`,
capped at 32 KB). It can shape the model's behavior however you like, but it
is only text for the model: approval and the privilege-escalation guard are
enforced in code and cannot be turned off by it.

## Tools and approval

| Tool  | Approval | Notes |
|-------|----------|-------|
| read  | no       | numbered lines, 2000 per call, `offset`/`limit` to page |
| bash  | yes      | fresh `bash -c` per call in the working directory; no tty, no stdin; 120 s default timeout (max 600); output over 30,000 chars is cut in the middle |
| edit  | yes      | `old_text` must match exactly once; you approve the exact diff that will be written |
| write | yes      | creates parent dirs; overwrites are shown as a diff |

The approval box shows the exact command or diff. `y` approves, `n` denies,
`r` denies with a reason that is passed to the model. Changes outside the
launch directory are marked **OUTSIDE PROJECT**.

### Privilege escalation

Commands mentioning `sudo`, `su`, `doas`, `pkexec`, `run0` or "with administrator
privileges" are refused before you are asked. Commands also run without a
controlling terminal, with a failing `sudo` first on `PATH`. This is a
guard, not a sandbox: approve commands with care.

## `!` commands

`!cmd` runs `cmd` yourself (no approval, same guard) and adds the command and
its output to the conversation; the model sees it with your next message.
It is not an interactive shell: no tty, no stdin, no pagers.

A bare `!cd DIR` changes bridle's working directory for all later commands
and tells the model. `cd` inside a longer command (`!cd x && make`) does
not persist.

## Keys

| Key | Action |
|---|---|
| Enter | send (when idle) |
| Alt-Enter, Ctrl-J | new line |
| Ctrl-V / Alt-V | scroll half a screen forward / back |
| PgDn / PgUp | scroll a screen forward / back |
| Ctrl-X o | show/hide tool output |
| Ctrl-X t | show/hide thinking (hidden by default) |
| Ctrl-X w | wire inspector (raw JSON of each exchange) |
| Ctrl-C | interrupt; clear input; twice on empty input to quit |

Input editing: Ctrl-F/B (char), Alt-F/B (word), Ctrl-A/E (line start/end),
Ctrl-P/N (line up/down), Ctrl-D/H (delete char), Alt-D / Alt-Backspace
(kill word), Ctrl-K / Ctrl-U (kill to end/start of line), Ctrl-Y (yank).
On macOS the terminal must send Option as Meta.

Commands: `/new` starts a fresh conversation, `/quit` exits.

Inside tmux, note that tmux's default prefix (Ctrl-B) and the screen-style
Ctrl-A both shadow editing keys; press the prefix twice to send it through,
or pick another prefix.

## Logs

Each session writes to `.bridle/sessions/` in the launch directory:

- `<time>.md` — readable transcript, including every tool call, approval
  decision and result
- `<time>.jsonl` — one line per model request: the full request body and
  the assembled response (plus raw SSE lines with `--wire-raw`)

`.bridle/` contains a `.gitignore` so logs are never committed.

    cargo test                              # unit and loop tests, no server needed
    cargo test --test live -- --ignored     # talks to llama-server on :9931
    scripts/smoke.sh                        # end-to-end in tmux against a live server

## How it works

- `src/agent.rs` — the loop: call the model, run tool calls (asking for
  approval), append results, repeat until the model stops calling tools
- `src/llm/stream.rs` — reassembles the streamed response, including tool
  calls whose arguments arrive in fragments
- `src/tools/` — the four tools and the guard
- `src/ui/` — the terminal interface; it talks to the agent only through
  `src/events.rs`
````
